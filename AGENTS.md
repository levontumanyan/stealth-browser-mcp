# AGENTS.md

- **Layout**: `bin/stealth_browser.py` is the canonical MCP server + CLI source; `bin/stealth-browser` is a symlink preserving the legacy `uv run --script` path. `bin/stealth-browser-audit` (transcript mining) stays a standalone PEP 723 script. The server is packaged as `stealthmcp` with a `stealth-browser` console script. Keep the PEP 723 block and `pyproject.toml` dependencies identical (test enforces this).
- **Tests**: Run with `uv sync --locked && uv run pytest tests/ -x`. Tests load the server module via `SourceFileLoader` from `bin/stealth-browser` (repo-root-relative), so no compilation or PATH setup is needed.
- **Skills**: `skills/<name>/SKILL.md` is the canonical, shareable location for workflows around these CLIs. Harnesses discover this directory via `~/.gemini/config/skills.json` (AGY) and the `skills` array in `opencode.jsonc` (OpenCode) — never copy skills elsewhere.
- **Shipper deployment**: The Postgres shipper is personal infrastructure and lives outside this repo, in the private `home_directory` dotfiles repo (`scripts/stealth-browser-shipper` + the `com.levon.stealth-browser-audit-shipper` LaunchAgent). It reuses `bin/stealth-browser-audit` from this repo as its parsing source of truth.
- **MCP registration points**: the installed `stealth-browser` console script (`uv tool install stealthmcp`), registered via `claude mcp add -s user stealth-browser -- stealth-browser` or `opencode mcp add --global`. Existing local configs using an absolute checkout path remain valid via the symlink.
- **Style**: Indent with one tab per hierarchy level. Every CLI subcommand must appear in `--help`. Keep code self-explanatory with zero comments; place context and rationale in commit or PR bodies.
